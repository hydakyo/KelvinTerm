Terminal workspace

Everything you need between the rack and the shell.

KelvinTerm consolidates the daily tools of infrastructure work without turning your Mac into a toolbox of disconnected utilities.

⌁

SSH sessions that stay organised

Saved connections, favorites, recent sessions, fuzzy Quick Open, tab restore, tab rename and local port forwarding. Passwords stay in macOS Keychain.

$ ssh admin@edge-fw
Connected · host key verified
⌘

Serial console, instantly

Detect USB console cables as they appear, reconnect automatically and control DTR, RTS and BREAK without another app.

▣

SFTP beside your terminal

Browse remote files from the active SSH session. Transfer files or folders with progress, cancel and resume.

⚡

Reusable command library

Store commands, scope them to sessions and use {parameter} placeholders. Review before sending to live equipment.

◎

A workspace that remembers

Restore previous tabs, spot background activity, search full scrollback, record ANSI output and export readable transcripts.

  • 02 Define a DHCP pool for the isolated link.
  • 03 Start once; KelvinTerm handles the privileged helper.

Native by design

Your sessions stay on your Mac.

Local-first storage. Session profiles, commands and workspace state live in your user Application Support directory.

Keychain for SSH passwords. Credentials are not written into profile JSON or exports.

Native OpenSSH. KelvinTerm keeps host-key verification, SSH agent and keyboard-interactive behaviour in the macOS OpenSSH stack.

No account required. Download the app and work locally.
