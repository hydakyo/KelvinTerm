One focused workspace

Built for the work between the cable and the CLI.

KelvinTerm keeps the everyday network-engineering tools close together, without turning the interface into a dashboard.

↕
01 / CONSOLE

From cable to console in seconds.

KelvinTerm watches for USB serial devices and can open the right port automatically. Newly detected consoles stay temporary until you choose Save. Previously saved ports keep their configuration. When you need lower-level control, DTR, RTS and BREAK are already there.

Automatic USB discovery Manual serial configuration DTR · RTS · BREAK

02 / DIRECT-LINK DHCP

When the device doesn’t have an address yet.

Connect a physical Ethernet adapter, define a small pool and serve only that isolated link. It is built for staging, bench work and first-touch configuration — not as a general LAN DHCP server.

Scoped to one physical adapter One-time privileged helper approval Lease visibility inside KelvinTerm
⇄
03 / TFTP SERVER

Move files on the isolated link.

Choose an Ethernet adapter and a local folder. Devices can download from KelvinTerm on UDP 69; enable uploads only when you need them. New uploads never replace existing files.

Per-adapter · Download-only by default · Transfer history
▤
04 / SESSION LOGS

Return to a recorded session.

Recording saves the ANSI file you choose and keeps a private copy in Logs. Search past sessions and open one in a read-only terminal with its colors intact. Resize the recording list to make more room for long names or terminal output; its width is remembered.

Searchable · Read-only replay · 100 or 200 entries
A practical workflow

Plug in. Give it an address. Configure. Connect.

KelvinTerm is designed around the point where a device is still on your desk, not yet in DNS, and sometimes not even on the network.

01
Find the console.

Auto-detect a USB serial cable or choose the port manually.

02
Give the device an address.

Use direct-link DHCP when you need a temporary isolated network.

03
Move a configuration file.

Serve a file over TFTP on that link when the device needs it.

04
Move into SSH.

Save the session, open SFTP, start a tunnel, or record the work for later review.

Still a terminal at heart

See the signal in your terminal.

Local shell, SSH and serial sessions share the same focused terminal experience, with restrained text highlighting, search, recording, a searchable Logs library and a compact status bar. Important addresses and operational states stand out while ordinary output stays quiet.

  • Read addresses in cyan, healthy states in green, warnings in amber and failures in coral
  • Keep existing ANSI colors and your terminal theme intact
  • Rename and reorder tabs
  • Search terminal scrollback
  • Record sessions and replay them in the read-only Logs terminal
  • Organize connections into customer or system Groups and search sessions directly
  • Switch terminal themes and font size quickly

Native and local-first

Feels like a Mac app because it is one.

macOS Keychain

Saved SSH passwords stay in Keychain instead of profile files or exports.

System OpenSSH

Host-key verification, SSH agent and keyboard-interactive authentication stay in the macOS OpenSSH stack.

Local workspace

Profiles, commands, workspace state and private recording copies stay under your user Application Support directory.

No KelvinTerm account

Open the app and work. The current product does not depend on a KelvinTerm cloud account.

Download for macOS v0.4.10 Release notes
v0.4.10 · Requires macOS 14 Sonoma or later.

New in 0.4.10: fixes deleting saved SSH connections when macOS Keychain reports an ownership error. The app authorizes access and deletes the exact password item directly from the login keychain. Includes 3 Latest Sessions, up to 20 Recent connections, local shells starting in Home and custom terminal text colours.

Current builds use Apple Development signing and are not notarized. On first launch, macOS may ask you to right-click KelvinTerm and choose Open. DHCP and TFTP use a shared helper that can require one administrator approval on first use or after an update.
