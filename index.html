Direct-link networking

Console the device, give it an address, then SSH into it.

KelvinTerm’s DHCP helper is designed for a physical USB or Thunderbolt Ethernet adapter on a direct or isolated link.

  1. 1Select the physical adapter.
  2. 2Choose the DHCP pool and optional gateway.
  3. 3Install the privileged helper once with administrator approval.
  4. 4Later starts are silent; active leases appear in KelvinTerm.

Native and local-first

KelvinTerm keeps the operational model simple.

Local profiles

Sessions, commands and workspace state live under your user Application Support directory.

macOS Keychain

Saved SSH passwords are stored in Keychain, not inside profile JSON or exports.

macOS OpenSSH

SSH agent, host-key checks and keyboard-interactive authentication stay with the system OpenSSH stack.

No account required

KelvinTerm is a local native app; the current workflow does not depend on a KelvinTerm cloud account.
